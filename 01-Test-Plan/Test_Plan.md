# TEST PLAN
## E-Commerce Web Application Testing

### 1. Project Overview
- Project Name: E-Commerce Web Application Testing
- Application Under Test: SauceDemo
- Application Type: Web Application
- Testing Type: Manual Testing
- Testing Methodology: Black Box Testing
- QA Role: Junior QA Engineer

### 2. Testing Objective
Tujuan dari pengujian ini adalah untuk memverifikasi bahwa fungsi-fungsi utama aplikasi e-commerce berjalan sesuai dengan persyaratan yang telah ditetapkan.
Pengujian akan berfokus pada identifikasi defect, validasi alur kerja user, serta memastikan bahwa aplikasi menyediakan fungsionalitas yang diharapkan.

### 3. Scope of Testing

#### In Scope
- Login functionality
- Product inventory
- Product sorting
- Product details
- Shopping cart
- Checkout form
- Order completion

#### Out of Scope
- Backend API testing
- Database testing
- Load testing
- Security penetration testing
- Payment gateway integration testing

### 4. Testing Approach
Pengujian akan dilakukan secara manual dengan menggunakan metodologi pengujian Black Box Testing.

Pendekatan pengujian mencakup:
- Functional testing
- Positive testing
- Negative testing
- Exploratory testing
- Regression testing

Skenario pengujian dan kasus pengujian akan dirancang berdasarkan persyaratan yang telah ditetapkan. Hasil aktual akan dibandingkan dengan hasil yang diharapkan untuk mengidentifikasi defect.

### 5. Test Environment
- Application: SauceDemo
- Application URL: https://www.saucedemo.com/
- Testing Platform: Web Browser
- Browser: Google Chrome
- Operating System: Windows.
- Testing Type: Manual Testing

### 6. Entry Criteria
Pengujian dapat dimulai ketika:
- Aplikasi tersebut dapat diakses.
- Lingkungan pengujian tersedia.
- Persyaratan pengujian telah ditinjau.
- Kredensial pengujian yang sah tersedia.
- Fitur-fitur utama aplikasi sudah siap untuk diuji.

### 7. Exit Criteria
Pengujian dapat dianggap selesai bila:
- Semua kasus uji yang direncanakan telah dijalankan.
- Hasil pengujian telah didokumentasikan.
- Defect yang teridentifikasi telah dilaporkan.
- Cacat kritis telah ditinjau.
- Laporan ringkasan pengujian telah selesai.

### 8. Risk Assessment

| Risk | Impact | Mitigation |
|---|---|---|
| Application unavailable | High | Retry testing and document downtime |
| Test account issue | Medium | Verify account availability |
| Defect not detected | High | Improve test coverage |
| Application changes during testing | Medium | Perform retesting |
| Test evidence missing | Medium | Save screenshots during execution |

### 9. Deliverables
- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Report
- Bug Reports
- Test Summary Report
- Test Evidence
- Requirement Traceability Matrix

### 10. Conclusion
Rencana pengujian ini menetapkan lingkup, pendekatan, lingkungan, risiko, serta kriteria pengujian untuk aplikasi web e-commerce.
Proses pengujian akan berfokus pada validasi fungsionalitas utama pengguna dan identifikasi cacat melalui pengujian Manual Blackbox Testing.
